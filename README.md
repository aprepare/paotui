# 校园跑腿小程序

## 项目概述
一个基于 uni-app + Vue3 的微信小程序，提供校园跑腿、二手交易、校园论坛等功能。

## 技术栈
- **前端框架：** uni-app + Vue3（组合式 API，script setup）
- **构建工具：** Vite
- **UI：** 手写样式，无第三方UI库
- **后端：** 微信云开发（待接入）
- **目标平台：** 微信小程序

## 设计规范
- **主色：** #4A90D9（蓝色）
- **辅色：** #FF6B6B（红橙色，价格/强调）
- **背景色：** #F5F7FA
- **卡片样式：** 白色背景、border-radius: 16rpx、box-shadow: 0 4rpx 12rpx rgba(0,0,0,0.08)
- **字体：** 标题 32rpx 加粗、正文 28rpx、辅助 24rpx #999
- **按钮：** 圆角渐变，主按钮用蓝色渐变

## 功能模块

### 1. 跑腿服务
- 用户发布跑腿订单（代取快递/代买东西/代打印/其他）
- 跑腿员抢单（先到先得）
- 订单状态流转：待接单 → 已接单 → 配送中 → 已完成
- 报酬设置（预设金额 + 自定义）

### 2. 二手市场
- 发布二手商品（图片、标题、价格、分类、描述）
- 商品列表（双列瀑布流布局）
- 商品详情（图片轮播、卖家信息）
- 联系卖家

### 3. 校园广场/论坛
- 发帖（文字 + 图片）
- 帖子列表（头像、昵称、时间、内容）
- 点赞、评论功能
- 内容安全检测（需接入微信内容安全API）

### 4. 用户中心
- 微信授权登录
- 个人信息展示
- 我的订单/商品/帖子
- 钱包/收藏/设置

## 开发命令
```bash
npm install                  # 安装依赖
npm run dev:mp-weixin        # 编译到微信小程序（开发模式）
npm run build:mp-weixin      # 编译到微信小程序（生产模式）
```

## 编码规范
- 使用 Vue3 组合式 API（script setup + ref/reactive）
- 样式使用 scoped，单位用 rpx
- 页面跳转用 uni.navigateTo / uni.switchTab
- 所有用户输入需过内容安全检测
